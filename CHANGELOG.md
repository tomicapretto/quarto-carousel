# Changelog

## 1.1.0

- Keep interactive Bootstrap carousels in Quarto HTML documents.
- Show native images, captions and text steps in PDF via Typst. Static images
  use 85% width and captions retain line breaks and inline formatting.
- Accept `.item` slides, Markdown images and figures alongside `.carousel-item`.
- Preserve figure identifiers, numbering, cross-references and image resources.
  HTML references show the carousel step containing the figure.
- Render the example as HTML and PDF, with collapsible code blocks in HTML.
